# RMarket Storefront

Welcome to the official repository for **RMarket**, a modern digital general store selling groceries, apparel, and daily wellness items.

## Tech Stack
* **Frontend:** HTML5, Tailwind CSS
* **E-Commerce Backend:** Snipcart API
* **Hosting:** GitHub Pages (Free static hosting)

## Setup
1. Clone this repository.
2. Replace `YOUR_SNIPCART_API_KEY_HERE` in `index.html` with your live Snipcart API key.
3. Commit and push changes to trigger a GitHub Pages automatic deployment.
